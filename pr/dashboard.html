How the forecast is calculated

Each forecast month uses the average gross earnings for each category of up to three recent completed months with recorded payments.

If only the current month has payments, the forecast uses twice the average earnings per paid run for each category, assuming two runs per month.

Runs count once they are marked Paid and have a payment date. Without qualifying payouts, the forecast is unavailable.
